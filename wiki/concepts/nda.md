# NDA

The non-disclosure agreement covering the Meridian Markets engagement. Per Dana Okafor's brief, it must be signed before IT will release the data extract, and it establishes the non-negotiable rule that customer records and employee data — including loyalty program data and labor schedules, in full or as excerpts — must never go into ChatGPT, Claude, Copilot, or any other AI tool; sales totals by store/week and store attributes are explicitly cleared for AI tool use. The data handling checklist formalizes this rule into a more detailed data classification table (see [Data classification (AI tool use)](data-classification.md)).
